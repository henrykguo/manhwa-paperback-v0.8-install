# ManhwaUS for Paperback v0.8

This public repository contains generated installer files for the ManhwaUS Paperback extension. The TypeScript source remains in the private source repository.

Add this repository to Paperback using:

`https://worrybigbig.github.io/manhwa-paperback-v0.8-install/`

Built with `@paperback/types` and `@paperback/toolchain` 0.8.7.

Discover includes expandable Latest Updates, Trending, and Top Rated lists. The Latest Updates (No Raw) list hides titles ending in ‘raw’.
